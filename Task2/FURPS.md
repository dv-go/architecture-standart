| Код | Требования                                                                      | Комментарий                                                 |
|-----|---------------------------------------------------------------------------------|-------------------------------------------------------------|
| F   | Функциональные (Functionality)                                                  |                                                             |
|     | Клиент сайта может подать заявку на депозит с указанием ФИО и телефона          | Базовая функция MVP для новых клиентов                      |
|     | Менеджер кол-центра изучает заявку и предлагает персональные условия            | Обработка заявок с возможностью вариативности условий       |
|     | **Клиент интернет-банка видит доступные и персональные ставки и подаёт заявку** | Функциональность для текущих клиентов                       |
|     | **Заявка в интернет-банке подтверждается СМС-кодом**                            | Аутентификация и подтверждение намерений клиента            |
|     | Менеджер бэк-офиса вручную подтверждает условия депозита в АБС                  | Этап обработки заявки в MVP                                 |
|     | Клиент получает СМС после подтверждения ставки и открытия депозита              | Подтверждение статуса для клиента                           |
|     | **Ставки по депозитам ведутся в XLS-файлах и доступны двум бэк-офисам**         | Текущий способ расчёта и координации условий                |
|     | Клиент должен пройти идентификацию в отделении после звонка                     | Юридическое требование для новых клиентов                   |
| U   | Удобство использования (Usability)                                              |                                                             |
|     | Интерфейс соответствует корпоративной дизайн-системе                            | Фирменные цвета и элементы интерфейса                       |
|     | Минимальный отклик интерфейса (миллисекунды)                                    | Ожидание высокой отзывчивости от пользователя               |
|     | Справочники загружаются за < 1 секунду                                          | Решение текущей проблемы с задержками в интерфейсе          |
| R   | Надёжность (Reliability)                                                        |                                                             |
|     | **Доступность интернет-банка и систем — 99.9% времени**                         | Ожидание надёжной работы 24/7                               |
|     | **Все сервисы работают круглосуточно (24/7)**                                   | Клиенты должны иметь постоянный доступ                      |
|     | **Избежать прямой интеграции интернет-банка с АБС**                             | Предотвращение нагрузки на перегруженную БД АБС             |
| P   | Производительность (Performance)                                                |                                                             |
|     | **Интернет-банк масштабируется горизонтально**                                  | Для распределения нагрузки и отказоустойчивости             |
|     | **Нагрузка равномерно распределяется между ЦОДами**                             | Для обеспечения непрерывной доступности                     |
|     | **АБС масштабируется только вертикально**                                       | Ограничение архитектуры, которое влияет на проектирование   |
|     | Быстрая загрузка справочных данных и интерфейсов                                | Реакция на замечания по текущей задержке                    |
| S   | Поддерживаемость (Supportability)                                               |                                                             |
|     | **Использование MS SQL и Oracle при разработке**                                | Совместимость с текущими технологиями в банке               |
|     | **Использование известных технологий и языков**                                 | Чтобы использовать существующую экспертизу                  |
|     | Разработка документации для масштабирования решения                             | Для будущего развития системы                               |
|     | **Kafka — желательная технология для очередей**                                 | На перспективу (не поддерживается текущей платформой)       |
| +R  | + Ограничения (Restrictions)                                                    |                                                             |
|     | **Шифрование трафика сайта при передаче заявки**                                | Обработка чувствительных персональных данных                |
|     | **Шифрование трафика интернет-банка при подаче заявки**                         | Необходимость защищать данные клиентов                      |
|     | **Избежать доработки СМС-модуля подрядчика**                                    | Чтобы реализовать весь функционал внутри банка              |
|     | **Не перегружать БД АБС при реализации новых процессов**                        | АБС уже испытывает нагрузку                                 |
|     | Резервный ЦОД доступен, но требует ручного переключения                         | Снижает отказоустойчивость интернет-банка в текущем виде    |
| F   | **Автоматическая регистрация заявки из интернет-банка в АБС**                   | Исключает ручной ввод на этапе масштабирования после MVP    |
| U   | **Адаптивный интерфейс интернет-банка для смартфонов**                          | Большая часть клиентов использует мобильные устройства      |
| R   | **Логирование действий клиента и ошибок при подаче заявки**                     | Упростит отладку, мониторинг и поддержку                    |
| P   | **Кэширование справочных данных**                                               | Снизит нагрузку на серверы и ускорит интерфейс              |
| S   | **Разделение бизнес-логики и UI интернет-банка**                                | Облегчит переход к микросервисной архитектуре в будущем     |
| +R  | **Все изменения должны быть согласованы с ИБ-службой**                          | Работа с ПДн и API требует контроля со стороны безопасности |
